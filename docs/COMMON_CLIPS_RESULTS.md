# Common clip results

The agreed first comparison uses the first 30 seconds of every local common clip. Processing is pending the demo-path verification and isolated laptop benchmark. No common-clip accuracy is measured yet.

Run `uv run python scripts/evaluate_common_clips.py Media/Sample --start 0 --duration 30 --workers 2` to create the ignored local runs and replace this page with neutral-ID coverage/stability tables. Observed-hand coverage is not recall, and the pipeline cannot identify wearer versus bystander hands reliably.

Human annotation packs are prepared locally. Keep label files and sheets private. Accuracy and agreement tables require completed, validated annotations; no provisional label is independently reviewed by default.
